# bamboo-old-house

A clean-room, from-scratch re-implementation of the idea behind **[yuukilike/bamboo-old-house](https://github.com/yuukilike/bamboo-old-house)** by [@yuukilike](https://github.com/yuukilike). The original project had no open-source licence, so no code or assets were copied: only the concept (and its public description) was used as inspiration. All code and assets in this repository are original.
